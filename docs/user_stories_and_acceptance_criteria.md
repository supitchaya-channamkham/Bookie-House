# User Stories, Acceptance Criteria & Test Cases
## โครงงาน Mini Project: ร้านขาย E-Book ออนไลน์ "Bookie House"

---

### 1. User Stories & Acceptance Criteria

#### US-01: การค้นหาและคัดกรองหนังสือ
- **As a** ลูกค้าทั่วไป
- **I want to** ค้นหาชื่อหนังสือและกรองตามหมวดหมู่ได้
- **So that** ฉันสามารถค้นหา E-Book ที่สนใจได้อย่างสะดวกรวดเร็ว
- **Acceptance Criteria (Given-When-Then):**
  - **Given** ลูกค้าเปิดหน้าแรกของ Bookie House
  - **When** พิมพ์คำค้นหาหรือเลือกหมวดหมู่หนังสือ
  - **Then** ระบบต้องแสดงผลเฉพาะหนังสือที่ตรงกับคำค้นหาและหมวดหมู่ที่เลือกแบบ Real-time

#### US-02: การสั่งซื้อและชำระเงินจำลอง
- **As a** ลูกค้าที่ต้องการซื้อ E-Book
- **I want to** สั่งซื้อหนังสือในตะกร้าและเลือกวิธีชำระเงินจำลอง
- **So that** ฉันสามารถดำเนินการซื้อได้อย่างปลอดภัยโดยไม่ต้องใช้บัตรเครดิตจริง
- **Acceptance Criteria (Given-When-Then):**
  - **Given** ลูกค้ามีรายการหนังสือในตะกร้าอย่างน้อย 1 รายการ
  - **When** กดยืนยันการสั่งซื้อพร้อมเลือกวิธีชำระเงินจำลอง (PromptPay Mock)
  - **Then** ระบบต้องบันทึกคำสั่งซื้อ สร้างข้อมูลการชำระเงิน และเคลียร์สินค้าออกจากตะกร้า

#### US-03: การดาวน์โหลดไฟล์ E-Book ตามเงื่อนไข
- **As a** ลูกค้าที่ชำระเงินเรียบร้อยแล้ว
- **I want to** เข้าถึงลิงก์ดาวน์โหลดหนังสือของตนเองได้
- **So that** ฉันสามารถนำไฟล์หนังสือดิจิทัลไปอ่านได้จริง
- **Acceptance Criteria (Given-When-Then):**
  - **Given** ลูกค้าเข้าสู่หน้ารายการสั่งซื้อ
  - **When** คำสั่งซื้อมีสถานะเป็น 'confirmed' (ยืนยันแล้ว)
  - **Then** ระบบต้องแสดงปุ่มลิงก์ดาวน์โหลดหนังสือที่ถูกต้อง
  - **And** หากคำสั่งซื้อมีสถานะ 'pending' หรือ 'cancelled' ระบบต้องไม่อนุญาตให้เปิดลิงก์ดาวน์โหลดเด็ดขาด

#### US-04: แอดมินตรวจสอบและอนุมัติคำสั่งซื้อ
- **As a** ผู้ดูแลระบบร้านค้า (Admin)
- **I want to** ตรวจสอบยอดเงินและอนุมัติคำสั่งซื้อ
- **So that** ร้านค้าสามารถส่งมอบสิทธิ์ดาวน์โหลดให้ลูกค้าได้อย่างถูกต้อง
- **Acceptance Criteria (Given-When-Then):**
  - **Given** แอดมินเข้าสู่หน้า Admin Dashboard
  - **When** กดปุ่ม "อนุมัติการชำระเงิน" ในคำสั่งซื้อที่รอตรวจสอบ
  - **Then** สถานะของคำสั่งซื้อจะเปลี่ยนเป็น 'confirmed' ทันที
